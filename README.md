# 小径分岔的花园 · The Garden of Forking Paths

> "时间永远分岔，通向无数的未来。" —— 博尔赫斯

一个 **AI 原生的网文创作与阅读平台**，以及驱动它的写作 agent —— **博尔赫斯（Borges）**。

## 一句话

任何人读到任何一章，都可以一键继承作者的全部世界观设定，从那一刻分岔出自己的故事线；分支可以再分支，无限分叉；分支被阅读，收益沿创作链与原作者共享。

## 三层结构

| 层 | 名字 | 是什么 |
|---|---|---|
| 写作引擎 | **Borges Harness** | 高约束的 AI 写作流水线：设定即代码，章章过审，禁止自由发挥 |
| 内容模型 | **故事树** | 章 = commit，故事线 = 分支，设定快照 = 任意章节时点的 canon 状态 |
| 平台 | **花园** | 免费阅读 + 广告变现 + 一键续写 + 分成沿祖先链瀑布分配 |

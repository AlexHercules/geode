# 构想：小径分岔的花园

## 起点

博尔赫斯在《小径分岔的花园》里写了一部不可能的小说：主人公在每个抉择点不选择其一，而是**同时选择全部**，让所有可能的未来并存。传统网文平台做不到这件事——一本书只有一个作者、一条主线、一个结局。

AI 原生写作让它第一次变得可能。

## 核心机制

### 1. 设定即资产（Canon Pack）

每本书的世界观、人物卡、时间线、力量体系、文风指南、未回收伏笔，全部以结构化文档（canon pack）维护，与正文一起按章节版本化。**任何一章都对应一份精确到该时刻的设定快照**——读者看到第 37 章时，能拿到的设定就是第 37 章为止的世界状态，不剧透后文。

### 2. 无痛继承，一键分岔

读者读到任何一章，点"从这里续写"：

1. 平台把该章时点的 canon pack 完整交给读者的写作 agent；
2. 读者用自然语言说"我想让女主在这里黑化"；
3. harness 基于继承的设定生成符合世界观的新章节，开出一条新分支。

续写者不需要读设定文档、不需要懂写作——继承是**无痛**的，这是和同人创作的本质区别：同人要自己脑补还原设定，这里设定是机器可读、机器可执行的。

### 3. 无限分支的故事树

分支可以再被分支。一本书不再是一条线，而是一棵不断生长的树（严格说是 DAG，未来可支持分支合并——两条线在某章汇流，这是连博尔赫斯都会喜欢的设定）。

- 每个节点 = 一章；
- 每条边 = "续写自"关系；
- 根 = 原作者的第一章；
- 读者的阅读路径 = 树上的一条根到叶的路径，读者在每个分岔点选择走哪条径。

### 4. 收益沿创作链共享

任何一章产生的广告收益，沿该章到根的祖先链分配（见商业模式文档）。原作者的世界观是整棵树的地基，树越茂盛，原作者收益越高——**这把"被二创"从侵权焦虑变成了原作者最希望发生的事**。

## 为什么是 AI 原生

- **供给侧**：写作门槛降到"会表达想法"即可，续写者数量比传统作者多两个数量级；
- **质量侧**：harness 的一致性审查保证每条分支都遵守世界观，不会出现 OOC（人物崩坏）的烂分支污染树；
- **冷启动**：平台自己用 harness 生产种子故事树，不依赖初期作者入驻。

## 名字

- 平台 / 项目：**小径分岔的花园**（The Garden of Forking Paths）
- 写作 agent：**博尔赫斯**（Borges）——园丁，不是国王。它执行设定，不发明设定；它修剪枝条，不决定树往哪长。

## 非目标（现阶段明确不做）

- 不做付费章节 / 订阅解锁（免费 + 广告，降低分岔的传播阻力）；
- 不做人工编辑审稿流（审查由 harness 的机器 gate 完成）；
- 不做多模态（插画、有声）——先把文字的树种活。

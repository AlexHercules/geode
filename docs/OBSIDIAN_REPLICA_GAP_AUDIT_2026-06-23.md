## 视觉与页面差距

### 1. 设置弹窗 IA 不匹配

Obsidian 参考截图的左栏结构是：

- 选项：关于、编辑器、文件与链接、外观、快捷键、钥匙串、核心插件、第三方插件
- 核心插件：白板、笔记重组、反向链接、快速切换、命令面板、模板、日记、同步、文件恢复、页面预览等
- 第三方插件：每个已启用插件一个设置入口

Geode 当前只有：

- 外观
- 插件
- 快捷键
- 命令面板
- 关于

主要问题：

- 编辑器、文件与链接、钥匙串、核心插件、第三方插件没有作为 Obsidian 同名页独立出现。
- 许多设置被塞进“外观”页，例如严格换行、行号、自动补全括号、默认新建位置、附件路径、模板、日记、页面预览等。这些在 Obsidian 中分属编辑器、文件与链接、核心插件设置。
- 左栏缺少 Obsidian 的分组标题和核心插件子项层级。
- 每个插件一个 Tab 的基础机制已在 R163 完成，但整体设置 IA 仍不是 Obsidian 的三段式导航。

优先级：最高。设置页是用户最容易感知“像不像 Obsidian”的地方。

### 2. 设置行样式接近但未达到像素级复刻

已接近的部分：

- 有左侧名称/描述、右侧控件的 setting row。
- Toggle、输入框、滑块、分隔线、右对齐控件都存在。

主要差距：

- Geode 弹窗整体更窄，内容区密度和 Obsidian 参考图不同。
- Geode 当前浅色图有明显蓝色 focus ring 包住整个设置弹窗，Obsidian 参考图没有这种视觉状态。
- Obsidian 多个设置组有更清晰的 section/card 分隔；Geode 当前多为连续行，分组感较弱。
- Obsidian 的下拉、管理按钮、图标按钮、取色器、开关的尺寸和阴影更接近原生桌面；Geode 控件偏 Web 表单风格。
- Obsidian 字体选择是“管理”按钮进入字体选择弹窗；Geode 当前是直接文本输入框。
- Obsidian 主题选择是下拉 + 管理；Geode 当前是深色/浅色/跟随系统 segmented control。

### 3. 快捷键页差距大

Obsidian 参考：

- 显示“280 个快捷键”。
- 顶部有搜索框、过滤按钮。
- 命令按来源分组，覆盖白板、表格、笔记重组、日记、书签、属性列表、数据库、同步、文件列表、反向链接、关系图谱、大纲、模板、编辑/格式、视图/外观、库/应用等。
- 每行右侧是当前键位 chip + 添加按钮。

Geode 当前：

- 运行时命令数 90，热键页显示 90 行。
- 搜索和“只显示已设置”筛选已经可用。
- 行右侧是键位 chip + “自定义”按钮，不是 Obsidian 的圆形加号/删除式控件。
- 没有 Obsidian 那种按插件/来源分组的完整命令清单。

确认已补的用户点名项：

- `删除当前文件` 已有。
- `切换左侧边栏`、`切换右侧边栏` 已有。

仍缺或不完整：

- `管理仓库` 未发现。
- Canvas/Bases/Sync/Publish/文件列表/窗口/多窗口/大量核心插件命令缺失。
- 命令分组与显示顺序不对齐。
- Obsidian 参考中的很多默认键位还没有逐项校准。

### 4. 插件设置页不匹配

Obsidian 第三方插件页包含：

- 安全模式
- 社区插件市场浏览
- 插件安装情况/检查更新
- 自动检查插件更新
- 已安装插件列表：名称、版本、作者、描述、设置、启停、删除

Geode 当前插件页：

- 分为内置、外部、Obsidian 三组。
- 内置插件有开关。
- Obsidian 社区插件卸载入口已通过 `r166` 测试。
- 缺少 Obsidian 的安全模式/市场/插件更新/自动更新结构。
- 核心插件和第三方插件没有拆成 Obsidian 同名顶级页。

这意味着 B1/B2 的能力有一部分，但视觉和信息架构仍不忠实。

### 5. 文件树右键菜单差距

Obsidian 文件树右键菜单参考项：

- 在新标签页中打开
- 在右侧标签页打开
- 在新窗口中打开
- 创建副本
- 移动到其他文件夹
- 复制库内路径 / 复制 Obsidian 链接
- 打开历史
- 使用默认应用打开
- 在系统访达中显示
- 重命名
- 删除

Geode 当前文件夹右键截图显示：

- 在此新建笔记
- 在此新建文件夹
- 移动到
- 重命名
- 删除

源码显示文件右键另有：

- 在新标签页打开
- 在右侧打开
- 创建副本
- 移动到
- 重命名
- 删除

仍缺：

- 在新窗口中打开
- 复制库内路径
- 复制 Obsidian 链接
- 打开历史/版本历史
- 使用默认应用打开
- 在访达中显示
- 菜单分组、宽度、阴影、浅色样式未对齐

### 6. 侧栏折叠：功能已修，视觉仍需对齐

当前测试结论：

- 左右侧栏可折叠。
- 折叠状态可持久化。
- 命令路径也可执行。

视觉差距：

- Geode 使用位于侧栏/主区边界中部的悬浮 chevron。
- Obsidian 的折叠入口更靠近标题栏/侧栏头部区域，整体与工作区 chrome 融合。

因此，用户提到的“无法收起”应更新为：“当前可收起，但折叠 affordance 的位置和 Obsidian 不完全一致。”

## 设置功能覆盖差距

### 编辑器

Obsidian 编辑器页包括：新标签页默认行为、默认编辑模式、视图状态切换、固定行宽、严格换行、笔记属性显示、折叠标题、折叠列表、行号、隐藏参考标记、RTL、拼写检查语言、自动补全英文标点、自动补全 Markdown 语法、智能列表、制表符、制表符宽度、自动转换 HTML、Vim 模式。

Geode 已有或部分已有：

- 固定行宽
- 严格换行
- 行号
- 折叠标题
- 自动补全括号
- 制表符/缩进宽度
- 默认新标签视图
- 拼写检查开关

主要差距：

- 没有独立“编辑器”设置页。
- 许多选项位置错误，被放在外观页。
- 拼写检查语言、自动补全英文标点、自动转换 HTML、Vim 模式、RTL、隐藏参考标记等未完整呈现。
- 笔记属性显示已有相关能力，但 UI 不等同 Obsidian 的下拉项。

### 文件与链接

Obsidian 文件与链接页包括：默认打开文件、新笔记存放位置、附件路径、内部链接类型、自动更新内部链接、Wiki 链接、检测附件类型文件、删除确认、删除附件策略、删除文件设置、忽略文件、切换设置文件夹、URI 链接、重建缓存。

Geode 已有或部分已有：

- 自动更新内部链接
- Wiki/Markdown 链接设置
- 链接路径格式
- 新笔记默认位置
- 附件路径
- 忽略文件
- 本地 `.trash`
- `obsidian://` 内部处理能力

主要差距：

- 没有独立“文件与链接”页。
- 删除确认、删除附件策略、系统回收站/本地回收站/永久删除的 UI 未完整复刻。
- 设置文件夹切换、URI 链接开关、重建缓存没有按参考图呈现。
- 默认打开文件未完整呈现。

### 外观

Geode 已有或部分已有：

- 深色/浅色/跟随系统
- 强调色
- 界面/正文/等宽字体
- 字号
- 可读行宽
- inline title
- ribbon 显隐
- tab title bar / status bar 显隐

主要差距：

- 主题市场/已安装主题管理 UI 不完整。
- 字体“管理”弹窗未复刻，当前是文本框。
- 快速调整字体大小、缩放比例、原生菜单、窗口边框样式、自定义应用图标、半透明效果、硬件加速等未按 Obsidian UI 呈现。

### 关于、账户、钥匙串

Obsidian 包含：安装程序版本、检查更新、自动更新、语言、帮助、账户、Catalyst、商用许可证、高级启动通知、命令行界面、钥匙串密钥列表。

Geode 当前“关于”更像产品说明页。

主要差距：

- 账户/许可体系未复刻。
- 钥匙串独立页缺失。
- CLI 设置缺失。
- 帮助/翻译入口缺失。
- 关于页信息结构和 Obsidian 不同。

### 核心插件

Obsidian 核心插件总表和各插件设置页是复刻重点。Geode 已实现很多核心能力，但 UI 尚未按 Obsidian 核心插件页组织。

仍缺或远期的大件：

- Canvas 白板
- Bases 数据库
- Sync/Publish 若以“完整复刻”为目标仍需要明确替代策略
- Web clipper
- Audio recorder
- Markdown 格式转换器
- Pop-out / 多窗口
- Stacked tabs
- Vault 管理/切换器

已实现但需要 IA 对齐的能力：

- 反向链接/出链
- 关系图谱
- 快速切换
- 命令面板
- 模板
- 日记
- 文件恢复
- 书签
- Properties
- 页面预览

## 插件兼容层差距

`OBSIDIAN-COMPAT.md` 的当前结论是：高频核心 API 覆盖不错，但不追求 100% 兼容。若用户目标改为“完整复刻 Obsidian”，以下就不能只当远期记录：

- `getResourcePath` / Tauri asset protocol
- Lucide 图标覆盖
- `parseYaml` / `stringifyYaml`
- `editorInfoField` 等 CM6 StateField
- `adapter.stat`
- `App.lastEvent`
- `registerObsidianProtocolHandler` 派发
- `registerExtensions`
- Bases / Value / 新 Settings 声明式 API
- SecretStorage / Keychain 对应能力
- Popout / 多窗口 API

注意：其中多项需要新依赖或 Rust/host 集成，不属于小修小补。

## 优先级建议

### P0：先把“看起来不像”的面修掉

1. 重构 SettingsModal IA：拆出“编辑器 / 文件与链接 / 外观 / 快捷键 / 钥匙串 / 核心插件 / 第三方插件 / 关于”，把现有控件迁移到正确页面。
2. 设置页视觉按 `reference/00-界面复刻规范.md` 做像素级校准：弹窗尺寸、左栏宽度、section header、setting item 行高、控件样式、浅/深主题。
3. 热键页扩展为 Obsidian 结构：280 条目标清单、来源分组、默认键位、添加/删除按钮样式。
4. 文件树和编辑器右键菜单补齐 Obsidian 菜单项。
5. 侧栏折叠保留当前行为，但把 affordance 位置和视觉对齐 Obsidian。

### P1：补设置页背后的真实功能

1. Vault 管理/切换器与“管理仓库”命令。
2. 文件与链接页删除策略、附件删除策略、URI 开关、缓存重建。
3. 编辑器页 Vim、RTL、拼写检查语言、自动 HTML 转换、隐藏参考标记。
4. 关于/账户/钥匙串/CLI 页。
5. 第三方插件安全模式、市场、更新检查、已安装插件列表。

### P2：大件功能

1. Canvas。
2. Bases。
3. Pop-out / 多窗口。
4. Stacked tabs。
5. Web clipper / Audio recorder / Markdown converter。
6. Plugin API 剩余高价值项：getResourcePath、Lucide、parseYaml、editor fields、protocol dispatch。

## 最终判断

Geode 当前不是“完整复刻 Obsidian”，但已经有不少底层能力。最大的差距不是单个控件能不能工作，而是：

- 设置页信息架构与 Obsidian 不一致。
- 快捷键命令覆盖只有 90/280。
- 右键菜单、插件管理、关于/账户/钥匙串、核心插件设置页仍未按 Obsidian 表面复刻。
- 视觉规范还没有进入逐像素验收阶段。

如果目标明确为完整复刻，下一轮不建议继续先做差异化延伸。应先以 `reference/` 为验收标准，做一轮“设置与热键总表复刻”，因为这是当前最影响 Obsidian 用户迁移感知的缺口。

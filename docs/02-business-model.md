# 商业模式

## 基本盘：免费阅读 + 广告（番茄模式）

读者免费读全文，章间 / 章内插入广告，广告收入是平台的现金流。这一模式已被番茄小说验证：免费换规模，规模换 eCPM。

```
广告主 → 平台（广告收入）
                ├─ 平台抽成（如 40%–50%）
                └─ 创作者池（按阅读分配，沿祖先链瀑布分成）
```

## 核心差异：祖先链瀑布分成（Royalty Waterfall）

一次章节阅读产生的创作者收益 R，沿该章到根的创作链分配：

- **当前分支作者拿大头**（如 70%）——激励续写；
- **剩余 30% 沿祖先链按衰减系数分配**（如每上溯一层 ×0.5，归一化）——激励开源世界观；
- 原作者（根节点）额外拿一份**世界观税**（如全树收益的 5%）——保证树长得再深，根永远有收益。

示例：读者读了第 4 层分支上的一章，收益 100：

| 角色 | 份额 |
|---|---|
| 该章作者（第 4 层续写者） | 70 |
| 第 3 层、第 2 层续写者 | 30 按 0.5 衰减分配 ≈ 17 + 8.5 |
| 原作者（根 + 世界观税） | ≈ 4.5 + 全树 5% |

> 系数全部可调，写进每棵树的"分成章程"，创建时锁定，对所有续写者透明。

**这个机制把平台的增长飞轮和创作者利益绑死了**：原作者最优策略是把设定写得越完整、越可继承越好；续写者最优策略是选热门树的好分岔点。二创不再是侵权，而是给原作者打工。

## 第二曲线收入

1. **写作侧订阅（SaaS）**：博尔赫斯 harness 的使用额度——免费档每月 N 章，重度续写者付费。这是写作者付费，与阅读免费不冲突；
2. **去广告会员**：会员费按同样的瀑布规则分给创作链；
3. **分岔点竞价**：热门章节的"续写推荐位"有限，分支作者可竞价曝光（类似搜索广告）；
4. **IP 衍生**：整棵树的数据天然标注了"哪条线读者最爱"，对影视 / 游戏改编方是已验证的剧本市场。

## 冷启动路径

1. **阶段 0（现在）**：harness 写出第一棵种子树（1 本书 + 官方示范分支）；
2. **阶段 1**：邀请制——找 50 个网文重度读者体验"一键续写"，验证分岔意愿；
3. **阶段 2**：开放阅读端，接程序化广告，跑通最小分成结算；
4. **阶段 3**：开放任何人建根（发新书），平台变成花园。

## 关键风险

| 风险 | 应对 |
|---|---|
| AI 内容监管 / 平台资质（网文需出版物网络传播资质） | 早期出海或挂靠现有持证平台；内容全量标注 AI 生成 |
| 烂分支污染（低质续写损害树的口碑） | harness 质量 gate 是发布前置条件；阅读量自然排序埋葬烂分支 |
| 原作者冷启动意愿（凭什么把设定开放？） | 世界观税 + 数据证明：被分岔的书总收益 > 不开放的书 |
| 广告 eCPM 撑不起分成 | 番茄已验证规模可行；早期用订阅收入补贴 |
| 抄袭 / 设定搬运（把别家 IP 喂进来建树） | 建根时查重 + 侵权下架连带整棵树，分岔者有动机举报烂根 |

> **用途**：280 命令总表的*正确前置*。先有这张「Obsidian 命令 → Geode 命令 id → 状态」对照，再决定补哪些命令/热键页行——避免对已存在命令重复劳动（R179/R180 教训：命令面远比审计「90 vs 280」标题富）。
>
> **权威源**：`reference/_截图/04-热键/热键-01…16.png`（16 张完整滚动，页眉「显示 280 个快捷键」，按**拼音排序**）+ `reference/04-热键命令.md` 摘要。⚠️ `reference/` 在 git 仓库**上一级**（与 `geode/`、`deepnotion/` 同级），故仓库内 `git` 看不到、但磁盘可读——上一轮「不在仓库」是发现性误报，非真缺。
>
> **列含义**：
> - **Obsidian 命令 / 默认键** = 截图逐字转写（权威，1.9.10 + 插件 Calendar/Claudien/ePub Reader/Folo）。
> - **Geode cmd id** = 本仓 `src` 实际注册的命令 id（`grep` 实证，见末尾盘点）。
> - **状态** 六态：`done` 真命令+真 handler+可绑键、对齐 Obsidian ｜ `partial` 命令在但不全（缺变体/缺默认键/缺部分行为）｜ `ui-only` 功能在但只在右键/按钮、无注册命令 ｜ `stub` 有命令但 handler 空/假 ｜ `missing` 完全缺 ｜ `oos` out-of-scope（依赖未建大件 Canvas/Bases/Sync，或不适用）。
> - **Obsidian cmd id** = 推断的规范 id；核心命令高置信，最终以 `obsidian.d.ts` / 实测命令面板为准（F2 类型对齐时复核）。
>
> **最后更新**：2026-06-24（R181 建立；R187 §4 方向性聚焦 4 partial→done；R188 §15 折叠/展开 2 partial→done；R189 §2 插入内部链接 partial→done + 补录 R186 §2 设为/移除小标题 7 项 missing→done；R190 §4 关闭其他/此组/组内其他 3 ui-only→done；R191 §3 多光标上/下 2 missing→done）。**实时 done/partial/missing tally 以 `ROADMAP.md` 取用纪律段为准**（§20 是 R181/R182 快照，未逐轮重排 R183–R187 增量；§1–15 各组小结已随轮更新）。

## 0 · 汇总

Geode 现注册命令：**88 条字面 id + 8 条动态 `app:go-to-tab-1…8` = 约 96 条**（已多于审计「90」）。下表按来源分组逐条对照，组内统计见各节小结，全局分布见末「状态分布」。

**结论先行**：Geode 已 `done` 的几乎全是**核心编辑/导航/面板**命令（高频写作闭环已通）；缺口集中在 ① 大件依赖组（白板/数据库/同步/表格编辑 = `oos`/`missing`）、② 文件操作的**命令版**（复制路径/重命名/移动 = 多为 `ui-only`，右键已有、未注册成命令）、③ 命令的**变体与默认键**（设为小标题 1-6、方向性聚焦标签组、在新窗口打开链接等 = `partial`/`missing`）。
